# Simple Python Calculator (Update)

A simple command-line calculator built with Python. This is one of my first Python projects, created while learning programming.

## Features

- Addition (`+`)
- Subtraction (`-`)
- Multiplication (`*`)
- Division (`/`)
- Exponentiation (`**`)
- Basic input validation using `try-except`

## How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Run the Python script using the Run button or press `F5`.

## How to Use

1. Enter `1` to start the calculator.
2. Enter `2` to exit.
3. Enter the first number.
4. Enter the second number.
5. Choose an operator: `+`, `-`, `*`, `/`, or `**`.
